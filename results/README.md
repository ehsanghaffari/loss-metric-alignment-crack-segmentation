# Final result archive

This directory contains compact outputs for the final four-dataset, six-loss, three-seed controlled demonstration (72 training runs). Primary advanced metrics are evaluated at validation-selected deployable thresholds; ODS and OIS are retained only as test-label-dependent oracle comparisons.

The large per-image result tables and native-resolution probability maps are intentionally not stored as ordinary Git files. They should be distributed through the versioned archival/release package used for peer review and publication.
