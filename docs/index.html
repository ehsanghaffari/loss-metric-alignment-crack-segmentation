Final controlled demonstration

The final study uses four public datasets, six prespecified losses, and three seeds: 72 training runs total. Saved probability maps are rescored offline so metric family, tolerance radius, threshold convention, and aggregation can be studied without retraining.

Crack500: Dice + Boundary has the highest mean global F1 (0.7392 ± 0.0004), while Dice + clDice has the highest clDice (0.8021 ± 0.0036) but the largest skeleton-length error (63.3% ± 13.3%).

Final v2 protocol

  • U-Net + ImageNet-pretrained ResNet-34
  • 448 × 448 random training crops; no resizing
  • AdamW, lr 1e-4, weight decay 1e-4
  • Cosine schedule; batch size 8
  • Exactly 100 epochs; early stopping disabled
  • Threshold grid 0.01–0.99; comparator p ≥ t
  • Relaxed radii 0, 2, 3, 4, 5 px
  • Boundary tolerance 2 px
  • Per-image and dataset-global aggregation
  • Explicit empty-mask rules
