# Loss–Metric Alignment for Deep Crack Segmentation

This repository contains the reproducibility code for *What to Optimize and How to Measure It: Loss–Metric Alignment for Deep Crack Segmentation*. The original 72-run U-Net/ResNet-34 pipeline is under `code/`, and the additional architecture, seed, calibration, geometry, annotation-sensitivity, skeleton-hole, and qualitative analyses are under `code/extended_analysis/`. Local paths are configurable through `PAPER3_ROOT`, `PAPER3_DATASETS`, `PAPER3_OUTPUT`, and `PAPER3_FIGURES`; public datasets are not redistributed, and the code is released under the MIT License.
