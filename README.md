# Loss–Metric Alignment for Deep Crack Segmentation

This repository contains the training, scoring, and revision-analysis code for *What to Optimize and How to Measure It: Loss–Metric Alignment for Deep Crack Segmentation*. The original 72-run U-Net/ResNet-34 pipeline is under `code/`, and the reviewer-requested extensions, including DeepLabV3+/ResNet-50 replication, additional U-Net seeds, per-image geometry, calibration, annotation-perturbation, skeleton-hole sensitivity, and qualitative analyses, are under `code/revision/`. Public datasets are not redistributed; code is released under the MIT License.
